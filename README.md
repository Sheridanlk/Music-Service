# Music Streaming Service

Музыкальный стриминговый сервис на Go с асинхронной обработкой аудиофайлов и потоковым воспроизведением в формате HLS.

Проект решает проблему централизованного хранения музыки и её прослушивания без необходимости скачивать аудиофайлы на устройства.

## Возможности

- **Управление медиатекой** — работа с треками через REST API.
- **Загрузка аудиофайлов** — загрузка и хранение музыки на сервере.
- **Потоковое воспроизведение** — передача аудио с использованием HLS.
- **Асинхронная обработка** — конвертация аудиофайлов в HLS с помощью FFmpeg в фоновых воркерах.
- **Очередь задач** — передача задач на обработку через RabbitMQ.
- **Хранение данных** — PostgreSQL для метаданных треков и MinIO для аудиофайлов.
- **Миграции БД** — управление изменениями схемы базы данных с помощью golang-migrate.
- **Контейнеризация** — запуск приложения и необходимых сервисов через Docker Compose.

## Технологический стек

| Технология | Назначение |
|---|---|
| Go | Реализация backend |
| REST API | Взаимодействие с клиентом |
| PostgreSQL | Хранение метаданных треков |
| RabbitMQ | Асинхронная обработка задач |
| MinIO | Хранение аудиофайлов и обработанных медиафайлов |
| FFmpeg | Конвертация аудио в HLS |
| HLS | Потоковая передача аудио |
| Docker | Контейнеризация приложения |
| Docker Compose | Запуск и взаимодействие сервисов |
| golang-migrate | Миграции базы данных |

### Обработка аудиофайлов

1. Клиент загружает аудиофайл через REST API.
2. Исходный файл сохраняется в MinIO.
3. API отправляет задачу на конвертацию в RabbitMQ.
4. Фоновый воркер получает задачу и запускает FFmpeg для преобразования аудио в HLS.
5. Обработанные файлы сохраняются в MinIO, а метаданные трека — в PostgreSQL.
6. Клиент запрашивает HLS-поток и воспроизводит аудио.

Асинхронная обработка позволяет вынести ресурсоёмкую конвертацию из основного потока обработки HTTP-запросов.

## Запуск проекта

### Требования

- Go
- Docker
- Docker Compose
- Git

### Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/Sheridanlk/Music-Service.git
cd Music-Service
```

### Конфигурация

Настройте переменные окружения, необходимые для подключения к PostgreSQL, RabbitMQ и MinIO.

### Запуск

Если проект настроен на запуск всех необходимых сервисов через Docker Compose:

```bash
docker compose up --build
```

Дополнительные шаги по настройке окружения и применению миграций зависят от конфигурации проекта.

## Цели проекта

- Практика разработки backend-приложений на Go.
- Реализация асинхронной обработки задач с помощью RabbitMQ.
- Интеграция PostgreSQL и S3-совместимого хранилища MinIO.
- Организация конвейера обработки аудио с использованием FFmpeg и HLS.
- Контейнеризация приложения и инфраструктурных компонентов.
